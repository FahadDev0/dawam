# دوام

محاكي حياة موظف ساخر في شركة تقنية سعودية خيالية. العب كمهندس backend عنده إطلاق بعد عشرة أيام، أو كموظف موارد بشرية يعالج طلبات الناس ومشاكلهم.

- ٩ شخصيات بحوارات وعلاقات وتعابير
- ٤ ألعاب مصغرة، وجوال داخل اللعبة
- أصوات وموسيقى مبنية على المقامات العربية
- ١٠ نهايات مختلفة

العبها من المتصفح على الجوال أو الكمبيوتر. التقدّم ينحفظ في جهازك.
